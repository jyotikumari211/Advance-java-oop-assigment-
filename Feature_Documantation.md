## Advanced Java OOP Assignment

### 1. Project Overview
This project contains 10 advanced-level Java programming exercises based on Object-Oriented Programming (OOP). The objective is to demonstrate the practical implementation of advanced Java concepts through real-world examples.

### 2. Features and Implementations

| No. | Program | Features | OOP Concepts |
|---|---|---|---|
| 1 | Payroll System | Calculates employee salaries | Inheritance, Abstraction, Polymorphism |
| 2 | Shape Interface Demo | Calculates areas of different shapes | Interfaces, Abstraction |
| 3 | Bank Management | Handles deposits, withdrawals and errors | Exception Handling, Encapsulation |
| 4 | Generic Repository | Stores and retrieves student records | Generics, Collections |
| 5 | Library Management | Manages book issuing and returning | Encapsulation, Collections |
| 6 | Ticket Booking | Handles multiple customers booking tickets | Multithreading, Synchronization |
| 7 | Strategy Pattern | Supports multiple payment methods | Interfaces, Polymorphism |
| 8 | Product Sorting | Sorts products by price and name | Comparable, Comparator |
| 9 | Student Management | Filters and sorts student records | Streams, Lambda Expressions |
| 10 | Thread-Safe Inventory | Manages stock during concurrent sales | Concurrent Collections, Atomic Variables |

### 3. Key OOP Concepts Used

**Inheritance:** Allows one class to acquire properties and methods from another class.

**Polymorphism:** Allows the same method or reference to behave differently depending on the object.

**Abstraction:** Hides implementation details and exposes essential functionality.

**Encapsulation:** Protects data by restricting direct access to class variables.

**Interfaces:** Define contracts that implementing classes must follow.
